# Todo App

Prosta aplikacja do zarządzania zadaniami zbudowana w React + Tailwind CSS.

## Funkcje

✅ Dodawanie nowych zadań
✅ Zaznaczanie jako gotowe
✅ Usuwanie zadań
✅ Automatyczne zapisywanie w przeglądarce
✅ Responsywny design
✅ Licznik postępu

## Jak uruchomić lokalnie

1. Sklonuj repo:
```bash
git clone <twoj-url-repo>
cd todo-app
```

2. Zainstaluj zależności:
```bash
npm install
```

3. Uruchom aplikację:
```bash
npm start
```

Aplikacja otworzy się na `http://localhost:3000`

## Deploy na Vercel

1. Wrzuć kod na GitHub
2. Otwórz https://vercel.com/new
3. Kliknij "Import GitHub Repository"
4. Wybierz swoje repo
5. Kliknij "Deploy"
6. Gotowe! 🚀

## Technologia

- React 18
- Tailwind CSS
- Lucide React (ikony)
- localStorage (do zapisywania)
